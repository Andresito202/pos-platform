# ADR-001: Monolito modular

## Estado

Aceptado.

## Decisión

El backend comenzará como monolito modular.

## Motivos

- menor costo operativo;
- transacciones consistentes;
- despliegue simple;
- mejor comprensión para el equipo;
- evita microservicios prematuros.

## Restricción

Los módulos deberán tener límites, contratos y propiedad de datos explícitos.
