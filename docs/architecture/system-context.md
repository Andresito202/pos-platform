# Contexto del sistema

## Componentes principales

- POS de escritorio.
- Panel web del propietario.
- Aplicación del comprador.
- Aplicación del domiciliario.
- Backoffice del proveedor.
- API central modular.
- Base de datos central.
- Base de datos local del POS.
- Servicio local de hardware.
- Sistema de sincronización.
- Servicio de actualizaciones.
- Auditoría y observabilidad.

## Modalidad híbrida

El POS confirma operaciones localmente y sincroniza con el backend central cuando exista conectividad.

## Modalidad local perpetua

El POS y su base de datos operan localmente sin dependencia permanente de Internet.

## Principio

La pérdida de conectividad no debe bloquear una venta ordinaria en el POS.
