# Modos de despliegue

## HYBRID

- POS instalado localmente.
- Base local.
- Operación offline temporal.
- Sincronización con backend central.
- Panel del propietario.
- Multisucursal.
- Domicilios.
- Backups en nube.
- Actualizaciones administradas.
- Suscripción mensual o anual.

## LOCAL_PERPETUAL

- POS instalado localmente.
- Base de datos local.
- Operación sin Internet.
- Licencia perpetua para una versión contratada.
- Actualizaciones mayores cobradas por separado.
- Sin dependencia de validación en línea permanente.
- Backup local bajo política definida.

## Regla

Ambas modalidades usarán una sola base de código.

La funcionalidad cambiará mediante:

- deployment mode;
- licencias;
- configuración;
- feature flags.
