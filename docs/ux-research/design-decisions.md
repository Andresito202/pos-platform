# Registro de decisiones de inspiración UX

Las referencias externas se utilizarán para analizar patrones, no para copiar interfaces.

Por cada referencia se documentará:

- producto observado;
- rol al que podría aplicar;
- tipo de comercio;
- distribución;
- flujo;
- componentes útiles;
- problemas detectados;
- elementos descartados;
- adaptación propuesta;
- decisión final.

## Referencias recibidas hasta ahora

- panel modular con botones grandes;
- catálogo visual para fruver y productos por peso;
- pantalla de venta con carrito lateral;
- factura térmica con datos fiscales, impuestos, CUFE y QR;
- diseño táctil para tenderos;
- panel tipo Shopify para propietarios.

## Decisiones preliminares

- botones grandes para funciones frecuentes;
- configuración fuera del primer nivel;
- interfaz diferente por rol;
- catálogo visual opcional;
- lector de código prioritario cuando existan muchos productos;
- plantilla de recibo configurable;
- diseño propio mediante un sistema de componentes y tokens.
